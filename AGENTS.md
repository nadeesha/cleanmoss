# Instructions for agents working on Cleanmoss

## Incremental commits

- Commit work incrementally in small, meaningful commits as each coherent change is completed and verified. Do not wait until the end of a long task to make one large commit.
- Run the checks appropriate to each change before committing, and use a clear commit message describing the change.
- Stage and commit only changes belonging to your task. Preserve unrelated work from the user or other agents, and never commit secrets or generated artifacts that should be ignored.
